## Mini Project — Simple Bank Account System

### Project Overview

The Simple Bank Account System is a menu-driven Python application that simulates basic banking operations. The account starts with a balance of 1,000 Birr and allows the user to check the balance, deposit money, withdraw money, and exit the application.

The program includes a three-attempt PIN verification system before granting access to the bank menu.

### Key Features

- **PIN Verification:** Allow a maximum of three attempts to enter the correct PIN.
- **Check Balance:** Display the current account balance.
- **Deposit Money:** Accept valid positive deposits and update the balance.
- **Withdraw Money:** Validate withdrawal amounts and prevent withdrawals exceeding the available balance.
- **Interactive Menu:** Display the menu repeatedly until the user chooses to exit.
- **Input Validation:** Handle invalid menu choices and reject zero or negative transaction amounts.
- **Transaction Counter:** Count successful deposits and withdrawals.

## Testing and Validation

The programs should be tested with normal inputs, boundary values, and unusual cases.

Examples include:

- Zero and negative numbers
- Equal numbers when comparing values
- Prime number boundary cases such as 0, 1, and 2
- Uppercase and lowercase letters in palindrome checks

- Invalid menu choices
- Zero or negative transaction amounts
- Withdrawals exceeding the available balance

Testing helps identify logical errors and improves the reliability of the programs.
